## 📌 Sobre este Repositório

Este repositório contém o código-fonte do meu portfólio pessoal, uma aplicação web de página única desenvolvida para apresentar minhas habilidades, projetos e informações de contato de forma profissional e interativa.

## 🎯 Objetivo

O objetivo deste projeto é servir como um cartão de visitas digital, demonstrando minhas habilidades através de suas próprias funcionalidades:

- 📚 Apresentar meu perfil profissional e acadêmico.
- 💼 Exibir meus projetos de forma dinâmica com modais interativos.
- 📱 Garantir uma experiência de usuário responsiva (desktop e mobile).
- ✨ Implementar funcionalidades como *light/dark mode* e animações de scroll.
- 🚀 Servir como um cartão de visitas digital interativo.

## 📂 Estrutura

O projeto está organizado da seguinte forma:

- **`index.html`**: Arquivo principal com a estrutura semântica da página.
- **`styles/`**: Contém os arquivos SASS (`.scss`) e o CSS compilado (`.css`).
- **`scripts/`**: Contém os arquivos JavaScript (`script.js`, `modal.js`) para toda a interatividade.
- **`assets/`**: Armazena imagens, ícones e o arquivo de CV.

## 🛠️ Tecnologias

- **Linguagem Principal**: HTML5, CSS3, JavaScript (ES6+)
- **Pré-processador**: SASS (SCSS)
- **Conceitos**: DOM Manipulation, Intersection Observer, LocalStorage, Design Responsivo
