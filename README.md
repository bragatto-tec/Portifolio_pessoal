## 📌 Sobre o Projeto

Este é o meu **portfólio pessoal**, um site desenvolvido para apresentar meus projetos, habilidades e experiências profissionais. O projeto foi construído utilizando apenas **HTML5**, **CSS3** e **JavaScript** vanilla, sem frameworks ou bibliotecas externas, demonstrando conhecimento sólido nas tecnologias fundamentais da web.

## ✨ Funcionalidades

- 🎨 **Design Responsivo**: Adaptável a todos os dispositivos (mobile, tablet, desktop)
- 🌓 **Tema Claro/Escuro**: Alternância entre modos de visualização
- 🎭 **Animações Suaves**: Transições e efeitos visuais atraentes
- 📱 **Menu Hambúrguer**: Navegação mobile otimizada
- 📧 **Formulário de Contato**: Sistema funcional para receber mensagens
- 🚀 **Performance Otimizada**: Carregamento rápido e código limpo
- ♿ **Acessibilidade**: Semântica HTML adequada e navegação por teclado



## 🛠️ Tecnologias Utilizadas

### Core Technologies
- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilização moderna com Flexbox e Grid
- **JavaScript**: Interatividade e funcionalidades dinâmicas

### Técnicas e Conceitos
- CSS Variables (Custom Properties)
- Flexbox e CSS Grid Layout
- Mobile-First Design
- Smooth Scrolling
- Intersection Observer API
- Local Storage (para persistência de tema)
- Manipulação do DOM
- Event Listeners
- Responsive Design com Media Queries

## ⚡ Performance

- ✅ Código otimizado e minificado
- ✅ Imagens comprimidas e otimizadas
- ✅ Lazy loading de imagens
- ✅ CSS e JS organizados e eficientes
- ✅ Sem dependências externas pesadas
