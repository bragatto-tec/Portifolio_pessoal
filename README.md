📌 Sobre este Projeto
Este repositório contém o código-fonte do meu portfólio pessoal, uma landing page interativa de página única projetada para exibir minhas habilidades, projetos e informações de contato de forma moderna e responsiva.

🎯 Funcionalidades Principais
O objetivo deste projeto é servir como um cartão de visitas digital, demonstrando minhas habilidades através de suas próprias funcionalidades:

🎨 Tema Escuro/Claro: Alternância de tema (light/dark mode) com salvamento da preferência do usuário no localStorage.

✨ Animação de Digitação: Efeito de "typing" dinâmico na seção 'Sobre' para apresentar o título e subtítulo.

🚀 Animação de Scroll: Seções aparecem suavemente (IntersectionObserver) conforme o usuário rola a página.

📦 Modal de Projetos: Carregamento dinâmico dos detalhes de cada projeto (armazenados em modal.js) em um pop-up modal, sem recarregar a página.

📱 Menu Mobile: Menu responsivo "hamburger" para navegação fluida em dispositivos móveis.

🖱️ Navegação Suave: Scroll suave para as âncoras internas (#sobre, #skills, etc.).

🛠️ Tecnologias Utilizadas
HTML5: Estrutura semântica do portfólio.

SASS (SCSS): Estilização avançada com variáveis, mixins e arquitetura modular.

JavaScript (Vanilla JS): Utilizado para toda a interatividade do site, incluindo o modal, menu, light mode e animações.

CSS3: Animações (@keyframes) e design responsivo (@media).
